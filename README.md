<h1>Guess The Historical Figure</h1>

The point of this game is to simply find a certain important history figure that's picked randomly by the computer, from a series of choices.

The game is solved by following enigmas using bash commands while providing hints, because the point of this game is not only solve it but also to learn facts about a certain historic figure that has marked our history as the human race. 

The hints will be provided at the beginning of each round, and if the player is taking a long time to answer a question, providing extra hints will be proposed.

<h2>Useful Commands</h2>

- **ls and its options** : lists the files and directories of the current directory
- **cd** : changes the directory
- **mkdir** : creates a new directory in the current repertory 
- **cp** : copies a file
- **mv** : renames a file
- **rm** : deletes a file
- **sudo apt install package** : installs software package
- **| (pipe)** : takes the output of one command and sends it as input to another command
- **grep** : searches text for patterns (filters the input)
- **ps aux** : shows what proceses are currently running 
- **kill** : terminates a running process
- **find [path] [options] [expression]** : search for files and directories based on name, type, size, date, owner, permissions, and more
- **pwd** : prints your current path (absolute path)
- **tar and its options** : compress and archives files
- **chmod and its options** : modifies the permission bits of a file or folder
  
<h2>Level 0 : Beginner</h2>
The goal of this level is to introduce the player to basic file navigation and essential Bash commands such as ls, cd, cat, and rm.

Clues are straightforward and factual, helping the player get familiar with how the game works. One or two hints should lead directly to the answer.

<h2>Level 1 : Intermidiate</h2>
This level helps the player practice creating, moving, and copying files using commands like mkdir, mv, cp, and grep.

The clues are a bit less obvious and require more thinking, encouraging the player to explore and combine different commands to find the solution.

<h2>Level 2 : Advanced</h2>
This final level challenges players to interpret abstract, symbolic, or coded hints.

The player must extract information from poetic or cryptic clues to identify the historical figure.
Commands such as grep, ps aux, tar, and kill can be used to reveal or piece together fragments of information hidden within the system.
